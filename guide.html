Random Site Locator: field guide

Quick card

  1. Job: details and the method from the spec.
  2. Lot & sites: enter each run. Sites appear by themselves.
  3. Plan (optional): add the drawing, tap two chainages.
  4. Report: check, Save PDF, Next lot.

First time on a phone

Open the link in Safari or Chrome, add it to your home screen, and open it once with signal. It then works offline and saves as you go.

1Job

Fill in the details and pick the method the spec names.

2Lot & sites

  • Add runs in the order laid: start, end, width, and near edge from datum (0 for the first).
  • Width changes? Width changes along the run. Soils: one run, length × width.
  • Can't test somewhere? Add excluded zone.
  • Set out each site's chainage and offset from datum. Measured a different width? Type it in the Width column.

3Plan

Photo or drop the drawing, tap Add chainage point at two readable chainages, type them in, then drag to fine-tune.

4Report

One A4 page with all workings. Save PDF to file it; Save HTML if you may need to reopen the lot (import it in Lots).

Rules

  • Set out to within 0.5 m. On a joint or pit, move to the nearest testable spot and note it.
  • Never pick sites yourself. The phone draws them; any change to the lot is recorded on the report.

Problems

Red message / no sitesFinish the lot details it names.
Overlay wrong side or widthPlan: flip Offsets go or adjust Width scale.
Lots missingUse the home-screen icon on the same phone, not a private tab.
