Quick start

  1. Open Random Sites from your home screen. The header should say Saved on this phone.
  2. Job: client, project, lot number, technician. Pick the method the specification names.
  3. Lot: each lane or paver run in the order it was laid, the number of sites, clearances and any excluded zones. Fix anything in red.
  4. Draw: tap Draw once. Only redraw if the lot details were wrong.
  5. Plan: photograph the supplied drawing, tap two or more spots where you can read the chainage, and type each chainage in.
  6. On site: set out each site and mark it Tested, Relocated or Not tested.
  7. Report: check it, then tap Start next lot for the next location.
  8. At the lab: Lots, Select all, Save reports.

Phone set-up (once)

  1. Open the app address the office gives you, in Safari on iPhone or Chrome on Android. Don't use a private or incognito tab.
  2. Add it to the home screen. iPhone: tap Share, then Add to Home Screen. Android: tap the ⋮ menu, then Add to Home screen or Install app.
  3. Open it once from the new icon while you have signal. After that it opens without signal.
Why the home screen mattersLots are saved inside the phone's browser. On iPhone, Safari can clear a website's saved data if it isn't opened for 7 days. A home-screen app isn't cleared that way. Either way, save the day's reports at the lab the same day.

Tap Help in the app header at any time to open this guide.

1Job

Fill in the client, project, location, lot number, ticket number, client reference, date, technician, material or layer, and test. These print at the top of the report.

Method

Use the method the contract specification names. If you aren't sure, ask your supervisor before you draw.

MethodWhat it does
WA 0.1 StratifiedSplits the lot into N sub-lots of equal area and puts one site in each. Sub-lots carry on from the end of one paver run into the start of the next.
WA 0.1 UnstratifiedSites can fall anywhere in the lot. Every spot has the same chance.
AS 1289.1.4.1Random number method. Sites anywhere along the length, with a random offset across the width.
AS 1289.1.4.2Stratified random number method. Splits the length into N equal strata and puts one site in each.

Select sites by

  • Location: cores, nuclear density, sand replacement, anything set out on the ground.
  • Time / tonnage / volume: sampling from production. You enter the total for the lot and the app gives the tonnage, volume or clock time for each sample.

2Lot

  • Measure along: Chainage (metres) or SLK (kilometres, e.g. 12.345).
  • Number of sites (N): from the specification.
  • Keep clear of longitudinal joints & edges (starts at 0.3 m) and transverse joints & ends (starts at 0.5 m). Set these to what the specification or your supervisor says. The starting values are not a requirement of the standards.
  • Offset datum: the edge that every offset is measured from. The default is the left-hand edge of seal, looking in the direction of increasing chainage.

Lanes and paver runs

Add one card for each lane or paver run, in the order it was laid. For each one enter:

  • Start and End chainage as it was laid. If a run was laid going down-chainage, the start is the bigger number.
  • Width of the lane or run.
  • Near edge from datum: how far the closest edge of this lane is from the datum. The first lane against the datum is 0. The next lane over is the width of the first lane.

Lane 1 sits against the datum, so its near edge is 0 m. Lane 2's near edge is 3.5 m from the datum. Site 6 is set out 5.07 m from the datum, which is 1.57 m into lane 2.

  • Add lane / paver run copies the last lane's chainages and width, and fills in the next near edge for you. Check it.
  • If a lane changes width part way, enter it as two lanes, split at the change.
  • On curves, measure along the chainage of the alignment and take offsets square to it.

Excluded zones

Add any part of the lot that can't be tested, such as a bridge deck, intersection, pit or hand-work area. Enter from and to chainage, which lanes it covers and the reason. The transverse clearance is kept around each zone, and every zone is listed on the report.

Check the lot

The panel at the bottom shows the testable length, area and sub-lot size, with a drawing of the lot. Red messages must be fixed before you can draw. Amber messages are warnings to read.

3Draw

  1. If the lab needs a subset (for example one MDD sample in every three sites), tick Also pick a random subset first and set the group size.
  2. Tap Draw random sites. The phone generates the random numbers. Never type in your own.
  3. The table lists each site's lane, chainage and offset from the datum, plus the random numbers used.
RedrawingOnly redraw if the lot details were wrong, such as a wrong chainage, the wrong number of sites, the wrong method, or the lot changed on site. You must pick a reason, and every draw stays on the report. Redrawing to get easier sites biases the result and isn't allowed.

If you change the method or lot after drawing, the app shows an amber warning. Redraw with the reason that fits.

4Plan

This step draws the lot and the sites on top of a photo of the supplied drawing. It is optional, but it is the quickest way to see where the sites are.

  1. Lay the drawing flat in good light and tap Take photo. Hold the phone square on, with the whole lot in frame.
  2. The app goes straight into adding points. Tap the drawing where you can read a chainage, then type that chainage into the box that appears (P1).
  3. Tap Add chainage point and repeat. You need at least two, as far apart as possible, ideally one near each end. On a curve, add more points around the bend.
  4. All points must sit on one line along the road, such as the set-out line, an edge line or the centreline.

Line it up

  • Datum from tapped line: if the line you tapped isn't the datum edge, slide this until the lot's datum edge sits on the datum on the drawing.
  • Offsets go Right of travel or Left of travel: if the lot appears on the wrong side of the line, flip this.
  • Width scale: many drawings aren't to scale across the road. Increase it until the lanes match the drawing. Leave it at × 1.0 for aerial photos and scaled plans.
  • Overlay strength: makes the lot more or less see-through.
  • Use + and − to zoom, and scroll to move around. Use Remove to delete a point that's wrong, then tap it again.
To testTestedRelocatedJoint / edge clearanceExcluded

The overlay is a guide only. Sites are always set out by measuring the chainage and offset.

5On site

Each site has a card with its chainage and offset from the datum in large numbers, plus the lane, sub-lot and distance from the lane edge.

  1. Set out the site by tape or wheel to within 0.5 m (WA 0.1 cl 4.2.1(h)).
  2. Do the test, then tap Mark tested.
  3. If the site lands on a joint, pit, structure or obstruction, move to the nearest testable spot. Tap Relocated and enter the actual chainage, actual offset and the reason.
  4. If a site can't be tested at all, tap Not tested and write the reason.

Measured width: if the lane is a different width at the site than you entered, open Measured width / notes and enter what you measured. The app recalculates the offset, as AS 1289.1.4.1 cl 3.2(d)(iii) requires. Set out to the new offset shown on the card.

For time, tonnage or volume sampling, each card shows when to take the sample. Tap Mark taken after taking it.

When every site has a result, a green message offers Check report and Start next lot.

6Report

The report shows on screen first, so you can check it before saving. An amber message lists any sites without an on-site result.

Add anything else the reviewer needs in Report notes. The report has lines for the technician, the checker and the date.

On iPhone, saved files go to the Files app, under Downloads.

Several lots in one trip

Every lot saves on the phone as you work, with or without signal. The header shows Saved on this phone and the time.

Start next lot keeps the job details, method, number of sites, clearances, datum, lane names, widths and near edges, and the drawing with its chainage points. It clears the lot number, chainages, excluded zones and sites. Enter the new lot number and chainages, check the lanes, then draw.

Tap Lots in the header to see every lot on the phone, grouped by date. Use Open to go back to one, or New job to start from blank.

Back at the lab

  1. Tap Lots, then Select all next to today.
  2. Tap Save reports. You get one file with every lot, each on its own pages. Tap Lot files as well if the lab keeps the raw records.
  3. File them as the lab procedure says.
  4. Once they're filed, delete the old lots from the phone. They stay until you delete them.

Rules that keep the draw compliant

  • Use the method the specification names.
  • Enter the lot as it really is, including every excluded zone.
  • Let the phone generate the random numbers. Draw before you look at the ground.
  • Don't redraw for convenience. Every redraw needs a reason and stays on the report.
  • Move a site only to the nearest testable spot, and record why.
  • Set out by measurement, not from the overlay.
